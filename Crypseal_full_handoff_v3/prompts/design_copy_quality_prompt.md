# Design and Copy Quality Prompt

Review the proposed feature as a premium mobile product.

Check:
- Is the flow understandable without developer context?
- Is the primary action obvious?
- Are risks and scope visible before execution?
- Is the copy human, concise, and specific?
- Does the UI recover well from failure?
- Does the screen feel like a product, not a terminal dump?

Return:
- blocking issues
- copy replacements
- design changes
- acceptance criteria
