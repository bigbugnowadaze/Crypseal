# Skill: Repository Map and Context Selection

Use when inspecting existing projects.

Rules:
- Start with file tree, ignore rules, package files, git status.
- Use grep/glob before reading large files.
- Include line-numbered excerpts.
- Build compact map of entrypoints, modules, key classes/functions.
- Never dump entire repo into model context.

Verification:
- Unknown repo summary contains entrypoints and test commands.
