# Skill: Node/Webapp Runner on Termux

Use for JS/TS/web apps.

Flow:
1. Inspect package.json.
2. Ask before `npm install`.
3. Prefer `npm test`, `npm run build`, or framework-specific checks.
4. For previews, start background process and monitor output.
5. Open localhost through app UI.

Watch for postinstall scripts and network/package risk.
